# 02: 查询并比较交通路线

**What to build:** 用户明确城市和起终点后，助手定位实际地点、查询适用交通方式，并比较有查询依据的耗时、距离和出行建议；地点或条件存在歧义时先澄清。

Blocked by: 01（跑通本地地点查询）

Status: ready-for-agent

- [x] 扩展开放清单，接入交通路线以及所需的地理编码、距离查询能力，使用高德实际发现的工具名称与参数结构。
- [x] 给定城市和明确起终点，查询适用的交通方式，分别展示实际返回的耗时、距离及路线信息，并说明比较结论。
- [x] 路线查询使用已确定的实际地点和坐标；同名地点无法区分时，结合城市、地址等信息澄清，不随意选择分店或其他城市地点。
- [x] 关键起终点信息缺失时先追问；复用本次对话中已明确的城市、地点和交通偏好，不重复询问。
- [x] 不编造未返回的耗时或费用；没有查询结果的交通方式不被表述为已经验证的路线。
- [x] 通过可控模型与地图返回验证地点确定后再查路线、参数正确转发、不同交通方式的结果均回传到模型；不严格断言真实模型措辞或无关的调用顺序。
- [x] 人工验收一条给定起终点的路线比较，并检查同名地点和缺失起点场景；实连不可用时明确记录验证限制。
