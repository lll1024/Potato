# 01: 跑通本地地点查询

**What to build:** 用户在本地命令行输入城市和地点关键词，旅行助手通过高德 MCP 查询地点并返回有查询依据的回答。完成从配置、连接、模型工具调用到结果展示的最小可运行闭环，为后续旅行能力提供可复用入口。

Blocked by: 无（可立即开始）

Status: ready-for-agent

- [x] 先将终端输入输出与核心循环分开，再接入地图工具；核心循环接收调用方提供的对话历史并返回最终回答，无需终端交互即可验证。
- [ ] 使用官方 SDK 和 Streamable HTTP 连接高德，采用异步模型与工具调用；确认实际协议兼容性并锁定依赖版本。
- [x] 从实际工具发现结果开放地点检索与详情查询，转换真实工具声明和参数结构；模型调用正确转发，文本及结构化结果正确关联回原调用。
- [x] 给定城市和关键词，CLI 返回查询到的地点及可用地址等详情，不将未查询到的信息当成事实。
- [x] 使用旅行助手系统提示词，移除全部现有编程工具；未知或未开放的工具不被转发。
- [x] 提供最小依赖、环境配置占位示例和运行说明，保留现有模型与兼容服务地址配置能力；缺失配置或启动失败时给出明确说明。
- [x] 提供有限的工具超时、模型轮数和调用次数作为基础约束；正常退出、中断或异常时释放连接。完整部分失败及预算终止回答由任务 04 完善。
- [x] 凭据不进入模型上下文、对话或日志，独立本地运行不共享历史，退出后不保存对话或行程；地图适配层不承担偏好存储职责，不提前实现记忆接口。
- [x] 通过核心循环的公开行为测试工具发现、开放清单、调用转发、结果对应及会话隔离；自动测试使用可控模型和地图返回，不依赖真实凭据。
- [x] 完成实际工具发现和一次低成本地点查询的冒烟验证；无可用凭据或服务不可用时，明确记录未完成项，不报告实连通过。
