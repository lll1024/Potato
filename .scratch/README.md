# 历史任务档案

本目录保存切换到 GitHub Issues 之前的规格、任务、讨论与验证记录。原文件保留原路径与内容，便于已有链接及历史证据继续追溯。

旧文件中的 `Status:`、任务勾选、分诊状态及待办文字描述的是当时阶段，不能据此认定任务现在尚未实施或需要认领。继续处理历史任务前，按[任务跟踪约定](../docs/agents/issue-tracker.md)核实实施、验收及当前 Issue，并为新的工作建立对应 Issue。

当前任务与规格从 [lll1024/Potato 的 GitHub Issues](https://github.com/lll1024/Potato/issues) 进入；代码入口见[后端职责地图](../docs/backend-map.md)，行为结论及证据见[验收索引](../docs/acceptance/README.md)。本目录不再作为新任务或当前进展的跟踪入口。
