# 默认资料获取与按需信息核实验收

2026-10-13 按已接受的 [ADR 0007](../adr/0007-information-retrieval-with-opt-in-verification.md) 实施。功能基于远程主分支 `4fff3d26ef43a18a4a19263d50240a5ff4d130ae`，不包含尚未合入主分支的后端目录重组。

## 行为与范围

普通规划主动获取所需资料，不为证明每条信息可靠而追加官方查证或交叉核对；用户明确要求时才专项核实，且仅覆盖当前问题与明确续问。普通问询直接依据资料回答，入口已有则附，明确要求时再寻找。已知冲突直接说明，由旅行者核实；缺失信息不编造。

CLI/Web 共用系统指令。历史回读、摘要与中断资料索引保留来源、日期和已知核实状态，但这些状态不再构成自动查证任务。原有 `historical_requires_recheck` 和 `recheck_required` 字段继续兼容保存与读取，其含义是资料尚未针对当前日期核实。网页资料展示不擅自标注官方身份，也不为缺失元数据逐项生成核实要求。

地图定位、交通、天气、外部工具协议、调用预算、完整历史与保存恢复规则继续保留；没有增加意图分类模型请求、持久化核实模式或新的配置。

## 测试入口与红绿记录

用户确认以 CLI/Web 最终回答、公开工具调用记录以及中断或失败时展示的查询资料验收。

- [展示失败记录](information-retrieval/projection-red.log.gz)：普通攻略被展示为“官方资料搜索线索（正文尚未核实）”。修正后展示为网页搜索资料，保留摘录、真实链接与原始载荷。
- [资料失败记录](information-retrieval/source-failure-red.log.gz)：读取失败被描述为“未完成正文核实”。修正后仅说明内容未取得，不将资料获取失败变成核实任务。
- 自动测试使用固定外部模型回复，仅验证公开 HTTP 展示、载荷与协议，不将预设回复视为模型语义验证。

## 真实模型行为

[验收脚本](../../tests/information_retrieval_eval.py) 使用现有模型配置，通过真实 CLI 或公开 HTTP 运行；地图、网页为固定 MCP 返回，`resume` 使用持久化未完成轮次夹具。没有调用真实景点网站，不将控制资料作为实际场馆政策。真实模型采样显式关闭上下文压缩，压缩与恢复机制另由自动回归覆盖。

脚本收集证据，退出码只说明运行是否完成；下面的语义结论经过逐条人工判读。回答、公开工具参数与状态及模型实际用量保存在压缩 JSON 中，[汇总](information-retrieval/manifest.json)记录各轮工具数量和耗时。

## 失败与修正

[早期专项回答](information-retrieval/verification-failed.json.gz)把来源身份未确认的闭馆资料写成确定结论，并补写未返回的实名预约要求；增加条件表达及不得从“需预约”推导实名、凭证与核验流程的规则后，最终专项样例保留未知状态。

[冲突失败样例](information-retrieval/conflict-failed.json.gz)仍补写未查询的展陈、咨询台和导览设施。Spec 审查指出此问题后，将缺失馆内资料的安排限制为到达、参观、休息、离开及建议时长；最终冲突样例未再补写上述细节。

[入口遗漏样例](information-retrieval/entry-omission.json.gz)在已取得入口后没有将链接附到后续普通规划。最终材料复审发现后，明确要求普通规划和改期保留与所选地点相关的已有入口；最终三轮样例均包含真实取得的链接，后两轮没有追加网页查询。[最后定向回归](information-retrieval/entry-fixed.log.gz)覆盖预算、摘要及公开资料展示，26 项通过。

[首轮全套回归](information-retrieval/full-initial.log.gz)运行 298 项，出现 26 个失败与 2 个错误，主要由系统指令增长导致的小窗口预算回归造成；另有未指定日期的资料展示提示缺失。没有扩大预算或降低断言要求。压缩重复专项规范后，系统指令从 10,364 字符降至 8,802 字符，基线为 8,874；恢复简短的日期未知提示。[摘要 13 项](information-retrieval/summary-fixed.log.gz)和[预算 11 项](information-retrieval/budget-fixed.log.gz)定向回归通过。

最后强化已有入口的保留要求后，系统指令为 8,845 字符，仍小于基线；上面的 26 项定向回归及 pyright 再次通过。

## 限制

行为选择仍由模型遵循指令完成，不是硬编码的意图分类或禁止联网。有限样例不保证所有措辞、后续会话或未来模型版本都完全遵循边界，也不保证所有回答无事实错误。正文和摘录可能不完整或过时；来源、库存、实际开放及预订均不能从资料获取成功推导。恢复夹具验证公开恢复行为，不等同于本次真实模型采样中的进程强杀实验；真实进程中断机制由自动回归覆盖。
