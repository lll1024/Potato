# 共享调用预算与最终回答收束验收（#74）

2026-10-13，功能分支 `codex/shared-call-budget`，基准主分支 `4f94ad48d7e7967fe32913c2b27243d3357482e8`。范围为 [Issue #74](https://github.com/lll1024/Potato/issues/74)，父规格 [#73](https://github.com/lll1024/Potato/issues/73)。

## 实现行为

Web 与 CLI 的每个对话轮次共用 128 次工具调用额度和 64 次实际模型请求额度。普通规划、网络失败重试、上下文恢复及摘要共用前 63 次；摘要原有单次两次、整轮四次上限，以及普通步骤五次网络重试和一次有效缩减恢复规则保留。逻辑步骤编号与实际请求序号分开，SDK 自动重试仍关闭，后台偏好提取保持独立。

工具额度耗尽或仅剩最后一次模型请求时，不再派发新查询，已提出工具逐项保留身份和未执行原因。最终请求使用已有资料、完整协议配对与有效上下文，关闭工具调用，不再摘要、恢复或重试，并重新检查完整输入容量。有效收尾也记录为 `terminated / budget`，展示已有资料及未完成限制；失败、无效内容、截断或容量不足则由应用明确终止。停止和保存故障继续优先，在途请求真实收束前保留运行名额。

## 公开边界证据

主要测试 [test_call_budget.py](../../tests/test_call_budget.py) 通过公开 `/api/turns`、HTTP/SSE、快照、载荷与重启回读运行真实循环、适配器和 SQLite，仅替换外部模型及地图/网页服务。混合工具场景运行真实地图 MCP 和网页 MCP/HTTP 协议。

| 场景 | 验证结果 |
| --- | --- |
| 第 63 次提出工具、第 64 次收尾 | 工具未执行且身份配对；最终请求无工具声明；状态未完成；重启不重放，新轮次序号重置为 1 |
| 规划、网络失败、摘要与恢复混合 | 同轮恰好 64 次真实请求，51 次失败也扣账；摘要与恢复属于同一普通步骤，最终用途单独记录 |
| 摘要使用第 63 次额度 | 有效及无效摘要均只使用剩余一次，不侵占最终额度，不再恢复原步骤 |
| 地图、网页与历史总额 | 地图 1 次、网页 119 次（含 1 次失败）、历史 8 次，共 128；第九次历史不扣总额，溢出网页未执行 |
| 最终服务失败、空内容、空白、截断、工具响应 | 最多 64 次，应用终止，无摘要、恢复或追加重试；无伪报成功 |
| 最终完整输入超过容量 | 根据真实返回用量向上校准后，第 64 次输入检查不允许发送；保留应用限制和原上下文 |
| 最终请求在途时用户停止 | 另一提交仍被拒绝，运行名额保留至真实失败返回；终态为用户停止且保留失败身份 |
| 最终开始记录保存失败 | 实际仅发出 63 次，保留此前成功地图资料；拒绝新提交；重启保留资料且不重放 |
| CLI 连续两轮 | 第一轮第 64 次关闭工具收尾，第二轮正常回答；SDK 自动重试为 0 |
| 浏览器预算终止 | 未完成提示与模型收尾正文同时可见；刷新不创建新提交 |

首个测试在实现前失败：第 64 次请求用途仍为 `travel`，没有预留最终请求。停止测试首次失败为 `budget` 覆盖 `user_stop`，修复后通过。原工具额度测试已更新为允许一次无工具的收尾请求，地图仍只执行预算内调用。
