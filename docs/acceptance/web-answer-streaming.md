# Web 最终回答流式展示（#98）

2026-11-05，范围为父规格 #97 的首个纵向任务 #98：Web 从公开提交、真实模型文本流到 SQLite 原子完成的完整链路。iOS、跨设备恢复、异常体验、阅读打磨及当前生产模型实连分别继续由 #99–#104 交付；本记录不表示这些任务已验收。

## 交付行为与边界

旅行规划明确分开资料获取和无工具最终作答，查询阶段的说明不进入正文或作为历史助手回答被回读。CLI 保留完整输出。新增作答占用逻辑步骤和实际请求，模型上下文重新检查完整容量；普通调用仍限前 63 次，第 64 次保留为无工具预算收尾，不新增摘要、恢复或重试。

会话在内存保存累计安全正文。公开快照及 `answer.preview` SSE 提供服务进程、持久数据集、会话、轮次、尝试与次序身份；预览不逐块写库，不推进持久轨迹游标。模型响应返回与原子完成分别表达，只有保存成功才转为历史回答。

Web 复用既有安全 Markdown、阅读跟随及分页。运行中显示“正在生成 · 尚未保存”，终态使用实际历史。正文不按字播放：普通中文可在无换行时分批出现，潜在敏感 URL、凭据头、未闭合结构及密钥匹配尾部按安全需要缓冲。
