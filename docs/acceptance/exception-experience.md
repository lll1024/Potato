# 异常结束体验验收

规格：lll1024/Potato#24。验证日期：2026-10-09。

## 产品行为

异常轮次用简短说明表达实际结束原因、保存事实及下一步。用户停止显示已停止；预算耗尽说明结果不完整；输出上限保留实际收到的模型文字。存储故障只确认最后成功保存的事实，仍停止接受输入。工具错误后模型正常完成继续属于“完成，含工具错误”。本机空闲显示“本机可接收输入”，不代表模型或地图恢复。

查询资料默认折叠，按已成功保存的返回整理，不额外调用模型。地点详情展示实际名称、地址、坐标及常规开放时间；候选标明尚未核实详情，常规时间不保证未来当日开放。天气逐项展示实际城市及预报日期；明确旅行日期不在覆盖范围时说明不能用于对应日期，未明确年份或日期时不自行推定春节年份。交通路线保留返回的两端、交通方式、耗时（秒）和距离（米），不补齐缺失字段或未查询衔接。无法识别或解析的返回仅提供处理记录入口，没有 JSON 正文回退或空资料容器。

“重新尝试”使用当前助手会话最近异常轮次的原输入，通过普通提交通道创建新的对话轮次及提交身份。保留失败记录，沿用现有完整协议上下文与查询预算，允许再次查询。整轮中断继续排除后续模型上下文；已保存资料可回看，不承诺全部恢复。草稿不被覆盖，即使草稿与原需求相同也不清空。全局忙、正在停止、待核对提交、本机不可用及地图暂停时禁用新重试；仍可编辑需求，并在允许输入时讨论已有资料。响应丢失后的核对及安全重试沿用原提交身份。

## 设计与接口

保留会话导航、对话／轨迹切换及底部输入区。异常说明之后提供恢复和记录操作，资料使用原生 details/summary，具有键盘操作、可见焦点和换行能力。每份资料可准确定位对应工具返回。展开状态按轮次在页面内保存，切换轨迹后恢复；沿用阅读跟随和显式“回到最新”。刷新或重开不自动执行。

会话快照增加 `query_materials` 和 `unreadable_query_count`。每份资料包含可读字段及说明，同时引用 `tool_call_id`、`payload_id`，摘要规则只在后端维护。摘要读取保存后的脱敏载荷，不迁移或改写历史回答、输入或工具记录，不改变 schema_version、执行身份、时间、usage、原始载荷读取、搜索、分段及完整复制契约。异常轮次及尚未完整结束轮次可整理已经成功保存的查询，正常完成回答保持现有呈现。存储故障通过既有 `unsaved_fact` 关联到轮次：即使最后保存状态仍为运行中，也在该轮显示未完整保存说明，不伪造失败终局、不继续显示执行动画；未保存返回不进入摘要。

## 限制

摘要只支持已确认返回形态和确定字段；其他形态可通过执行轨迹回看。日期检查识别输入中显式的公历年月日，只确认实际列出的预报日期，不把自然语言节日、未确认年份或未完整给出的日期范围自动转换为公历旅行日期。现有完整上下文续聊规则不变，摘要不承担正常模型回答的事实核查。测试使用可控故障，不探测或修复真实外部服务，也不引入自动重试、断点恢复、工具缓存或零重复查询保证。
