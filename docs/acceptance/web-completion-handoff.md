# #117 Web 可靠完成后的阅读交接

范围：公开 Web 页面与既有 HTTP / SSE；不改变后端预算、通知协议或 SQLite。真实模型连续体验由 #117 集成验收另行核验，本记录只陈述受控网络证据。

## 复现与验收

在 `conversation.spec.ts` 的「可靠完成到历史迟到期间正文连续且上翻保位」用例中，桌面 1440px 和手机 390px 已显示长回答、上翻暂停，然后收到匹配轮次的持久 `turn.finished`、活动轮次释放及正文／进展双 `null`，以 HTTP 响应屏障延迟历史。未修复时两端 `.answer-body` 都消失；红灯证据位于 `/tmp/web-handoff-117-red`。测试不使用固定等待隐藏交接窗口。

修复仅以持久完成通知授权独立阅读交接，保持规范预览为空。屏障期间正文与折叠查询进展保持可见、正文锚点不移动、复制按钮仍为「复制当前正文」；释放屏障后采用历史真实完整结尾及「复制完整回答」。另验证 invalidated、retrying、尝试替换、轮次变化、进程变化、页面切换与没有完成通知的普通 null 均不复活旧正文；既有停止、保存故障、平滑与 Markdown 用例保持原语义。

- 完整 `conversation.spec.ts`：53 项通过，含 9 项新增交接与失效用例；证据 `/tmp/web-handoff-117-conversation-full`。

- 生产构建、13 项呈现测试、模块边界、文档链接及 `git diff --check` 通过；Impeccable 局部检测无发现。
- 早期宽关键词执行误选上下文真实服务测试，新树缺少本地 `.venv` 导致两项 `ENOENT`，该次不计有效验证；随后补齐本地依赖链接。此记录不宣称已完成普通 Web 全量或真实模型终态验证。

## 限制

本记录不能替代真实模型 Web／iOS 连续采样，也不主张在没有可靠完成事实时保留预览。历史请求失败时只继续显示带当前正文语义的阅读交接，不伪造历史或已保存全文。页面离开即清除交接；进程重启后不恢复它。


## 完成后的迟到累计与状态宣布次序补充
