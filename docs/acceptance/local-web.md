## 可复现运行

安装与构建步骤以根 README 为准。实际干净环境为 Python 3.14.7、Node.js 24.19.0、npm 11.17.0：新空虚拟环境安装 `requirements-dev.txt`（含运行依赖）成功，`pip check` 无破损依赖；从 Git 提取到空目录后执行 README 的 `npm ci --prefix frontend` 和 `npm run build --prefix frontend` 成功，审计为 0 漏洞。未声称其他系统或版本已实测。

构建完成后日常执行 `python web.py`，同一服务在 `127.0.0.1:8000` 提供页面和同源接口；`--port` 和 `--data-dir` 可选择本机端口和记录目录，无需 Vite 或独立 Node 后端。正式入口固定一个工作进程。同目录第二实例和不支持的数据库版本均有中文拒绝提示。数据库、伴随文件和锁文件已排除 Git；自定义目录也应保留在版本控制之外。

