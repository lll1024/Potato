# 优先核实国内旅行信息并提供外部预订入口

工具扩展优先提升国内旅行行程的可信度，首批覆盖景区和博物馆的开放时间、预约规则、门票政策及临时公告。助手提供外部预订入口，由旅行者完成预约或预订；相比代预约和代下单，这一边界能先补齐规划所需的信息，避免在当前阶段引入订单、支付、取消和失败恢复的职责。

信息核实失败时保留原安排，明确标记待核实，并提供查询入口与备选建议；替换用户指定的地点仍需先确认。找不到具体预订页面时，允许提供官网首页、官方公众号或平台搜索入口，但须明确入口类型及后续操作；入口可访问不代表有票或已完成预订。入口选择须遵守官方渠道限制，不能因找不到具体预订页面而推荐官方明确未授权的代理渠道。

开放、预约和门票结论须由景区或博物馆官方渠道、政府文旅公告或官方指定的预订平台支撑。搜索结果用于发现线索，须读取来源正文并检查适用日期；常规开放规则不能单独证明未来某日一定开放。回答应关联具体来源，区分来源发布时间、查询时间和适用日期，缺失的信息仍标为待核实。

第一版补充当前时间上下文和相对旅行日期理解，约定见 [ADR 0003](0003-relative-travel-dates.md)；新增外部工具仅包括搜索和正文提取。遇到无法读取的动态页面、公众号或小程序，按上述待核实策略处理，暂不加入浏览器工具。外部服务先使用免费额度，额度耗尽或服务失败时保留已有查询资料并降级，不自动启用付费；资料核实失败不应阻止继续使用可用的高德工具完成有说明的旅行行程。
