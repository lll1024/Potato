# 旅行助手对话与执行轨迹 · 弃用交互原型

用于「通过原型确认对话与轨迹界面的交互」的 HITL 讨论。此原型不能进入产品主线；不调用真实模型或地图服务，不证明接口、保存或后台恢复已实现。

在仓库根目录运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory prototypes/trace-ui-prototype
```

打开 `http://127.0.0.1:8766/?variant=A`。原型仅含静态 HTML/CSS/JS，无依赖；历史、删除、重命名和发送均操作内存，刷新恢复预设样例。

- A：紧凑事件表与右侧详情，便于同时比较摘要与完整载荷。
- B：左侧轮次导航与行内详情，沿层级阅读；展开长载荷会拉长列表。
- C：时间线和表格在上，下方宽检查器，适合长 JSON；详情离选中行更远。

下方切换条或非输入状态下的左右方向键切换布局，URL 保留 `variant`。此静态目录没有生产构建或产品路由；整个目录均为原型，禁止部署到产品。

候选交互（尚未由用户选定）：最新轮次展开、旧轮次收起，模型请求下工具可收起；完整详情默认折叠。时间线选择对应事件。搜索默认当前会话全部载荷，包括折叠部分；匹配按钮展开对应层级和载荷并标出匹配。仅摘要范围可比较。长 JSON 可换行与复制，保留完整内容，控件不暗示真实服务返回。

试用：

1. 普通两轮追问：对话内“查看本轮轨迹”，定位模型请求及其完整输入快照。
2. 部分失败：定位超时调用，查看实际调用耗时和错误；轮次“完成，含工具错误”。
3. 预算终止：查看未执行调用，“—（未调用）”及应用回填；模拟缩小预算，不改变真实 64 次预算。
4. 运行中：切换历史、编辑草稿、尝试发送；停止时等模拟调用返回。点击“模拟当前调用返回”可结束本轮。此控制仅属于原型。
5. 历史模型失败：usage 未返回，已知汇总显示 1/2 覆盖，缓存真实模拟零与缺失区分。
6. 服务中断：结果未知、不补完成耗时，中断轮次提示排除后续上下文。
7. 新建后发送任意文字：生成新模拟轮次，切换保留草稿；重命名及删除只作用当前内存。

需要用户确认：布局及详情位置、默认展开、时间线与定位、搜索范围、滚动跟随及长 JSON 阅读。数据与会话语义继承已解决决策，不因 UI 候选变化重写。

限制：运行进度依赖演示按钮；刷新恢复样例，不能验证断线或真实持久化；这里没有可验证的真实模型快照、工具声明和服务器时钟。候选是评估界面的合成数据。向历史追加时仅模拟上下文关系，不能作为正式消息恢复实现。
